# Telegram Bot

Feature-rich Telegram bot with automated responses, custom command handling, and third-party API integrations.

## Features

- Custom command registration and handling
- Automated scheduled messages
- Inline keyboard and callback query support
- Third-party API data fetching (weather, news, etc.)
- User session management

## Tech Stack

Python, python-telegram-bot, Requests, SQLite

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/karthik-idikuda/Telegram_Bot.git
cd Telegram_Bot
pip install -r requirements.txt
```

### Usage

```bash
python bot.py
```
